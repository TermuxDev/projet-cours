Comment ca marche

1

Decouvre

Parcours le catalogue, filtre par categorie, trouve le cours qui te correspond.

2

Inscris-toi

Cree ton compte en 2 minutes, confirme ton e-mail avec le code recu, et rejoins un cours.

3

Apprends

Ouvre chaque chapitre, consulte sa ressource (video, article), a ton rythme.

4

Progresse

Marque chaque chapitre termine et regarde ta barre de progression se remplir.

Le projet derriere Cours+

Cours+ est un projet academique concu et developpe par Diomande Keuwe Mickael, dans le cadre des modules Java et Administration SQL Server. L'objectif : construire une plateforme complete - base de donnees relationnelle, API REST Spring Boot et interface Angular - en respectant les regles metier d'une vraie application d'apprentissage en ligne, de l'inscription a la validation de progression.
